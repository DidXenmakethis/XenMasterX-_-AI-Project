🎵 XenMasterX AI - Stüdyo Kalitesinde Ses Ayırıcı
Bu proje, yapay zeka kullanarak (Meta'nın Demucs V8 FT modeli) herhangi bir bölümün kalitesinde 4 parçaya (Vokal, Davul, Bass, Diğer) ayrılma. Spleeter gibi su altı ses vermez, frekansları kam gibi böler.

🚀 Özellikler
Node.js ve Express ile güçlü bir şekilde yazılmış arka uç.
Demucs (htdemucs_ft) ince ayarlı AI motoru özeti.
Kullanıcı dostu web arayüzü (HTML/CSS/JS).
Otomatik dosya adı temizleme ve Windows yol çözümleme sistemi.
🛠️ Kurulum
bilgisayarda Python, FFmpeg ve Node.js'in kurulu olduğundan emin olun.
Konsola npm installait gerekli depolar indirilir.
Konsola pip install -U demucsgönderilen AI motorunu yükle.
node server.jsile sunucuyu başlatıp http://localhost:3000 onaylanır!
